# Архив трибутов Капитолия

Статический сайт для публикации через GitHub Pages. Все анкеты хранятся непосредственно в `index.html`, поэтому содержимое одинаково для всех посетителей. Локальная база данных и `localStorage` не используются.

## Публикация
1. Загрузите содержимое папки `capitol_archive` в репозиторий GitHub.
2. В Settings → Pages выберите публикацию из ветки `main` и папки `/root`.
3. Музыкальные файлы разместите в папке `music/` в корне сайта.

## Музыка
Для каждого зарегистрированного живого трибута предусмотрены две композиции. Названия файлов указаны в данных анкеты и должны совпадать с именами в папке `music/`. Для Ильи Руднева первая композиция закреплена как `music4.mp3`; вторая — `03-001_track2.mp3`. Не переименовывайте файлы без изменения соответствующей записи в `index.html`.

Файлы аудио в архив не включены: добавьте собственные MP3-файлы с указанными именами. Фотографии не используются.

## Примечания
- Статусы зарегистрированных победителей — `АКТИВНО`.
- Дело `10-001` зарезервировано и пока не заполнено.
- Для Лилии Колиодис, Михаила Васягина и Сандры Росс некоторые сведения о возрасте или номере Игр оставлены неуказанными там, где их не было в исходных данных.
