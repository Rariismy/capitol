# Архив трибутов Капитолия

Статический сайт для GitHub Pages. Все активные анкеты находятся в `index.html`, поэтому содержимое одинаково для всех посетителей. Фотографии не используются.

## Публикация
1. Распакуйте архив.
2. Загрузите содержимое папки `capitol_archive` в корень GitHub-репозитория.
3. В настройках репозитория откройте **Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.
4. Загрузите MP3-файлы в папку `music/` с точными именами из списка ниже.

## Музыкальные файлы
Для каждого активного трибута предусмотрены две композиции. Первая запускается при открытии анкеты; после её окончания автоматически запускается вторая. Воспроизведение инициируется открытием анкеты (действием пользователя), поскольку браузеры блокируют автономный автозапуск звука. Кнопка с нотой в правом верхнем углу анкеты позволяет остановить или возобновить музыку.

## Реестр ликвидированных
В каждом из 12 дистриктов отображается по пять закрытых записей со статусом «ЛИКВИДИРОВАНО». Они не кликабельны и не раскрывают личности или сведения о трибутах. Номера закрытых дел не пересекаются с активными и зарезервированными номерами.

## Примечание
Сведения о возрасте или номере Игр, которые не были подтверждены, оставлены как неуказанные. Зарезервированное дело `10-001` сохранено.
