# Capitol Tribute Archive

Статический интерактивный сайт для GitHub Pages.

## Публикация
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. GitHub Pages опубликует сайт и покажет ссылку.

Пока доступна только папка Дистрикта № 10 и дело `10-001`. Остальные папки отображаются закрытыми.

## Сохранение
Изменения сохраняются в localStorage текущего браузера и устройства. Они не синхронизируются с другими устройствами и не становятся частью репозитория. Для резервной копии используйте «Экспортировать дело».
